# TaskFlow | مدیریت پروژه و وظایف

TaskFlow یک داشبورد مدرن برای مدیریت پروژه‌ها و وظایف تیمی است که با هدف ساده‌سازی مدیریت کارها، پیگیری وضعیت پروژه‌ها، کنترل زمان‌بندی و بررسی عملکرد تیم طراحی شده است.

## 📌 معرفی پروژه

در بسیاری از تیم‌ها، وظایف و اطلاعات پروژه‌ها در ابزارهای مختلف مانند پیام‌رسان‌ها، ایمیل و فایل‌های جداگانه پراکنده هستند. TaskFlow با ایجاد یک فضای متمرکز، امکان مدیریت پروژه‌ها و وظایف را در یک محیط ساده و منظم فراهم می‌کند.

این داشبورد به مدیران و اعضای تیم کمک می‌کند تا در یک نگاه وضعیت پروژه‌ها، وظایف عقب‌افتاده، میزان پیشرفت و فعالیت تیم را مشاهده کنند.

## 🚀 اجرای پروژه

ابتدا Repository را Clone کنید:

```bash
git clone https://github.com/your-username/taskflow.git
```

و وارد پوشه پروژه شوید:

```bash
cd taskflow
```

سپس فایل `index.html` را در مرورگر اجرا کنید.

این نسخه از پروژه برای اجرا به Backend یا ابزار Build خاصی نیاز ندارد.
